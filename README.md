# SantéLab V3
1. Supabase > SQL Editor : supabase_setup.sql, puis supabase_v2_laboratoires.sql, puis supabase_v3.sql (dans cet ordre, chacun une seule fois).

3. Installer l'APK, créer votre compte, exécuter la commande « Super Administrateur » (fin du fichier V2).
